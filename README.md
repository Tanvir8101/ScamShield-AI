## Project Description

ScamShield AI is a website where anyone can check a suspicious link, message, or email and quickly find out whether it looks like a scam. It shows a Low, Medium, or High risk level, explains why in simple words, and suggests what to do next.

## Proposed Features

- Authentication system
- AI scam text detector
- URL scanner
- Risk assessment (Low / Medium / High)
- AI explanation
- Scan history
- Scam reporting
- Safety recommendations
- Admin dashboard

## Technology Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js + Express.js
- **Database:** PostgreSQL
- **AI Integration:** OpenAI API / Gemini API
- **Machine Learning:** Python, Scikit-learn
- **URL Checking:** Google Safe Browsing API, PhishTank
- **Authentication:** JWT, password hashing
- **Deployment:** Vercel / Render
